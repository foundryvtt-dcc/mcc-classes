# Module Settings

Open **Configure Settings** and pick the *Mutant Crawl Classics (MCC) Class Character Sheets* section. All of the module's settings are world-scoped, so only the GM can change them.

Each setting names a compendium pack of RollTables to use for one category of MCC content, e.g. `my-homebrew.my-mutation-tables`. **Leave a setting blank** (the default) to use the Mutant Crawl Classics Core Book module's tables and world RollTables matched by name — see [Content Tables and Automation](Content-Tables.md) for the lookup order.

* **Mutation Tables Compendium** — the per-mutation check tables.
* **AI Program Tables Compendium** — the wetware-program check tables.
* **Artifact Tables Compendium** — the artifact check tables.
* **Glowburn Tables Compendium** — the per-patron glowburn manifestation tables.
* **Patron Taint Tables Compendium** — the per-patron Patron Taint tables, rolled on a natural 1 of an Invoke Patron AI check.

Changes take effect immediately — no reload needed.
