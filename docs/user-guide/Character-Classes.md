# Character Classes

MCC provides a dedicated actor sheet for each Mutant Crawl Classics class. Create a *Player* actor as usual, then open **Sheet Configuration** (the cog in the sheet's header) and pick the sheet matching the character's class — each sheet adds a class tab with the class's abilities, and swaps the DCC watermark on the Character tab for the MCC logo.

## Classes
* **Healer** — natural healing via a per-day **Naturopathy** pool: roll a heal (spending one use) from the sheet, and reset the pool to full after a rest.
* **Manimal** — natural attacks, Pack Mentality melee bonuses, and the manimal's AI recognition penalty.
* **Mutant** — mutations and mutation checks; drag mutation entries onto the sheet's Mutations list.
* **Plantient** — Hide in Greenery, Fragrance Pheromones, and natural thorn/spine attacks.
* **Rover** — artifact affinity, Doors/Security knack, and Darwinian Luck regeneration.
* **Sentinel** — the Artifact Die for artifact weapons and armor, plus the initiative bonus.
* **Shaman** — wetware programs granted by the shaman's AI patron; drag program items into the Programs list. Program casting supports [Glowburn and Patron Taint](Content-Tables.md).

Shared MCC fields (Archaic Alignment, AI Recognition, Artifact Check, Max Tech Level) appear on every MCC class sheet.

The rollable class abilities draw on tables from the Mutant Crawl Classics Core Book module (or your own tables) — see [Content Tables and Automation](Content-Tables.md).
