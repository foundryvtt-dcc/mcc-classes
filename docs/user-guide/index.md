# FoundryVTT Mutant Crawl Classics User Guide

This is the documentation for the FoundryVTT Mutant Crawl Classics (MCC) class sheets module (`mcc-classes`). It builds on top of the [Dungeon Crawl Classics (DCC) system](https://foundryvtt-dungeon-crawl-classics-user-guide.readthedocs.io/en/latest/) to support the Mutant Crawl Classics ruleset — everything in the DCC user guide still applies unless a page here says otherwise.
